# Contributing

Contributions are welcome.

This repository is distributed under the `PolyForm Noncommercial License 1.0.0`.
By submitting a contribution to this repository, you agree that your contribution is
provided under the same repository license terms. No separate contributor license
agreement (CLA) is required.

## Before You Contribute

- make sure your contribution is original or that you have the right to contribute it
- do not add third-party code, assets, or data with terms that conflict with this repository
- keep changes focused and documented
- update documentation when setup, behavior, or public interfaces change

## Suggested Workflow

1. Open an issue first for large changes or design-affecting updates.
2. Fork the repository and create a focused branch.
3. Run the relevant tests before submitting your changes.
4. Open a pull request with a clear summary of what changed and why.

## Quality Expectations

- follow the existing project structure and conventions
- keep code and documentation changes easy to review
- add or update tests when your change affects behavior
- explain any tradeoffs or limitations in the pull request description

## License Compatibility

Please only submit contributions that can legally be distributed under this repository's
license model. If you are unsure whether a dependency, code sample, or asset is compatible,
ask before submitting it.

## Respectful Collaboration

Be constructive, specific, and respectful in issues and pull requests. The goal is to
make the project better without creating unnecessary friction for other contributors.
