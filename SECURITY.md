# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately before sharing them in public.

Send reports to:

`puneetchandna21@gmail.com`

Please include as much detail as you can:

- affected component or file
- steps to reproduce the issue
- expected impact
- proof of concept, logs, or screenshots if available
- any suggested mitigation if you have one

## Responsible Disclosure

Please do not open a public GitHub issue for an unpatched security vulnerability.
Private reporting gives us a chance to investigate and reduce risk before public disclosure.

## Response Expectations

We will try to acknowledge valid security reports within 5 business days. Investigation
and remediation timelines can vary depending on severity, complexity, and maintainer
availability.
