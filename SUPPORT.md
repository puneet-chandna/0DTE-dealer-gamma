# Support

## General Questions

For general usage questions, setup help, and non-sensitive bug discussions, use GitHub
issues and any community discussion features enabled for this repository.

## Bug Reports and Feature Requests

Please use repository issues for reproducible bugs, documentation problems, and feature
requests.

## Security Issues

Do not report unpatched vulnerabilities in public issues.

Send security reports to:

`puneetchandna21@gmail.com`

For commercial licensing requests, business use questions, or partnership inquiries,

## Private Support

The maintainers may not be able to provide free private support for all requests. Using
public issue threads whenever appropriate helps keep answers discoverable for everyone.
